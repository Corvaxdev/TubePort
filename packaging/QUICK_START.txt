TubePort 2.1.3 — Quick Start
================================

1. Extract the entire ZIP archive.
2. Run Setup-Tools.cmd once while connected to the internet.
3. Wait for the verified tools to finish downloading.
4. Run TubePort.exe.
5. Paste a URL, choose your options, and click “Download.”

You do not need to install Python, yt-dlp, Deno, or FFmpeg manually. The setup
script downloads pinned upstream releases and verifies every SHA-256 digest
before placing the tools beside TubePort. Windows 10/11 x64 is supported.

For videos that require sign-in, open “Advanced options” and select your own
fresh cookies.txt file in Mozilla/Netscape format. This is the recommended
authenticated mode on Windows. The file is equivalent to an active account
session: do not share it, and delete it when it is no longer needed. Cookies are
not included in the package.

If Mozilla Firefox is installed, TubePort also offers its local profiles. The
Firefox choice appears only when firefox.exe is detected.

Why Chromium profiles are not shown on Windows:
- Chrome, Edge, Brave, Vivaldi, Opera, Chromium, and Whale may protect v20
  cookies with App-Bound/DPAPI encryption. Direct access from yt-dlp is not
  reliable, so TubePort deliberately does not offer those profiles.
- Closing the Chromium browser does not fix this encryption failure. Use a
  fresh cookies.txt export instead.
- Do not run TubePort as an administrator or disable browser security.

TubePort never asks for or accepts a username or password. Enter your credentials
only on the official YouTube, Google, or Instagram website in your regular browser.

Do not run the EXE directly from the ZIP archive or separate it from the
_internal folder. After setup, keep the tools folder beside it. For detailed
instructions, see README.html.

Package diagnostics:
  .\TubePort.exe --bundle-self-test --report-file .\bundle-report.json

Download only material that you have the right to use.
