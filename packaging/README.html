TubePort

A portable app for saving video and audio.

Version 2.1.4 · Windows 10/11 x64

Up and running in one minute

  1. Extract the entire ZIP archive to a regular folder. Do not run the EXE directly from the archive.
  2. Run Setup-Tools.cmd once while connected to the internet. It downloads pinned upstream tools and verifies their SHA-256 hashes.
  3. Open TubePort.exe. No Python installation or administrator privileges are required.
  4. Paste a URL, choose the quality and format, confirm the destination folder, and click “Download.”

Save location and download controls

  • TubePort resolves the current Windows Downloads Known Folder, including a location redirected by Windows or the user. Registry and profile-directory fallbacks are used when the Known Folder API is unavailable.
  • File Explorer may display the localized name “Загрузки” while the physical path is named Downloads. That does not mean there are two folders.
  • Choose folder… is a directory picker, so it intentionally shows folders and hides files.
  • Open save folder opens the active destination. After a successful download, the button becomes Show downloaded file and selects the exact result in File Explorer.
  • Cancel download stops the active downloader process tree and reports the attempt as canceled. Existing unrelated files are never deleted; a downloader-created partial file may remain.

What is included

Verified setupSetup-Tools.cmd retrieves yt-dlp, Deno, FFmpeg, and ffprobe from pinned upstream releases.
Portable after setupOnce the tools folder exists, you can carry the complete folder on a USB drive or copy it to another Windows computer.
Auditable packageExpected tool hashes are in TOOLS.lock.json; application hashes are in SHA256SUMS.txt.

Videos that require sign-in

TubePort never asks for a username or password. Sign in only on the official YouTube or Instagram website in your regular browser. Under “Advanced options,” select your own fresh Netscape-format cookies.txt file. This is the recommended authenticated mode on Windows.

If Mozilla Firefox is installed, TubePort also offers its local profiles. The Firefox choice appears only when firefox.exe is detected.

Authentication choices on Windows

cookies.txt file — recommendedSelect your own fresh cookie file in Mozilla/Netscape format. A JSON export is not compatible.
Detected Mozilla FirefoxWhen Firefox is installed, TubePort can ask yt-dlp to read cookies from the selected local Firefox profile.

A cookies.txt file effectively grants access to an active account session. Do not share it with anyone, upload it to public cloud storage, or keep it after it is no longer needed. Cookies are not included in the portable TubePort package.

Why Chromium profiles are not shown

TubePort deliberately does not offer Google Chrome, Microsoft Edge, Brave, Vivaldi, Opera, Chromium, or Whale profiles in its Windows interface. Current Chromium browsers can protect v20 cookies with App-Bound/DPAPI encryption, making direct access from yt-dlp unreliable.

  • Closing a Chromium browser does not fix App-Bound/DPAPI decryption failures.
  • Use a fresh cookies.txt file, or an installed Firefox profile when it is offered.
  • Do not run TubePort as an administrator or disable browser security to extract cookies.

Diagnostics without using the interface

In the app, open “Diagnostics and log.” To verify the package automatically, run the following command in PowerShell from the TubePort folder:

.\TubePort.exe --bundle-self-test --report-file .\bundle-report.json

To check a specific URL without downloading it:

.\TubePort.exe --debug-probe "URL" --report-file .\probe-report.json

To verify process-tree cancellation without downloading media:

.\TubePort.exe --cancellation-self-test --report-file .\cancellation-report.json

Current user logs are stored in %LOCALAPPDATA%\TubePort\logs. The “Copy report” button redacts the home-directory path and URL parameters.

The factory verification results for this build are stored in VERIFICATION.json.

Important

  • Download only material that you have the right to use, and follow the service’s rules.
  • Never enter your YouTube, Google, or Instagram password in TubePort. Sign-in must take place only on the official website in your browser.
  • This build is not digitally signed. Windows SmartScreen may display a warning the first time you run it.
  • Do not remove the EXE from its folder: the _internal directory and, after setup, the tools directory must remain beside it.
