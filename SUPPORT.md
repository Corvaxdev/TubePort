# Support

Use GitHub Issues for reproducible TubePort defects and focused feature
requests. Search existing issues first and use the provided forms.

Source-site extractor breakage may belong to yt-dlp. TubePort issues are most
useful for problems with its interface, URL validation, option mapping,
authentication selection, diagnostics, setup, or packaging.

Before posting diagnostics, remove filenames, profile labels, personal paths,
private URLs, account details, and any authentication material. Never post
cookies, passwords, tokens, browser databases, or private media.

Report vulnerabilities privately through the repository's Security tab as
described in [SECURITY.md](SECURITY.md).
